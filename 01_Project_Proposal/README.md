# Project Proposal: Food and Lifestyle of Hostellers

## 1. Problem statement
Hostel students manage meals, hydration, sleep, physical activity and food expenses alongside their academic schedules. These routines can vary across hostel arrangements and departments. Without organised data, it is difficult to describe common patterns and identify areas that may deserve attention.

## 2. Aim
To demonstrate how data analytics can summarise food habits and lifestyle patterns in a hosteller-focused coursework dataset.

## 3. Objectives
- Examine weekly breakfast, lunch and dinner frequency.
- Describe meal regularity, water intake and sleep duration.
- Explore physical activity and outside-food frequency.
- Summarise monthly food budgets and reported dominant lifestyle issues.
- Prepare reproducible outputs that can support a separately developed student dashboard.

## 4. Scope
The analysis covers the fields supplied in the coursework CSV. It is descriptive and educational. It does not diagnose health conditions, establish causation, or represent all hostellers.

## 5. Dataset and limitation
The supplied file contains 1,500 records and 16 columns. Its `Data Status` column explicitly marks all records as synthetic coursework data. Results must therefore be described as patterns in a synthetic dataset, not as findings from a real student survey.

## 6. Methodology
1. Inspect the source CSV and its schema.
2. Validate expected columns, missing values, duplicate IDs and plausible ranges.
3. Create a validated output dataset and a quality report.
4. Calculate descriptive statistics and grouped summaries.
5. Generate exploratory charts.
6. Use the outputs as reference material while the team independently develops its dashboard.

## 7. Expected outcome
A documented dataset, reproducible Python scripts, data-quality checks, summary tables and static exploratory charts. The interactive dashboard is a separate team deliverable.

## 8. Ethical use
Do not infer an individual's health from these data. If genuine student data are collected later, obtain appropriate consent, remove direct identifiers and follow institutional guidance.
