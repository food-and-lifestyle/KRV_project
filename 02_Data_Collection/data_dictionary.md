# Data Dictionary

| Field | Description | Unit / values |
|---|---|---|
| Hostel Type | Hostel or accommodation category | Category |
| Department | Academic department | Category |
| Meal Regularity Score | Numeric meal-regularity indicator | Score (source-defined) |
| Meal Habit Category | Meal-habit grouping | Category |
| Breakfast Days Per Week | Days breakfast is taken | Days/week |
| Lunch Days Per Week | Days lunch is taken | Days/week |
| Dinner Days Per Week | Days dinner is taken | Days/week |
| Daily Water Intake (Litres) | Daily water intake value | Litres/day |
| Sleep Hours Per Day | Daily sleep duration | Hours/day |
| Physical Activity (Hours Per Week) | Weekly physical activity duration | Hours/week |
| Outside Food Days Per Week | Days outside food is consumed | Days/week |
| Monthly Food Budget (INR) | Monthly food budget value | INR/month |
| Dominant Lifestyle Issue | Main issue category recorded | Category |
| Observation Date | Date field in the source dataset | Date |
| Record ID | Unique record identifier | Text ID |
| Data Status | Provenance/status label | Source-provided text |

**Important:** The source labels the records as synthetic coursework data. The score definition and category construction are not independently documented. Avoid treating them as validated clinical or population measures.
